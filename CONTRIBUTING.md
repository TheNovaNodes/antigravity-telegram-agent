# Contributing to AntigravityTelegramAgent

First off, thank you for considering contributing to AntigravityTelegramAgent!

## How to Contribute

1. **Fork the Repository:** Create a fork and clone it to your local machine.
2. **Environment Setup:** Make sure you have Python 3.10+ installed. Follow the quick installation guide in `README.md`.
3. **Run Tests:** Ensure you don't break existing functionality by running `python -m pytest` before making changes.
4. **Make Changes:** Try to keep your pull requests focused on a single issue or feature.
5. **Update Documentation:** If you add a new feature or change existing behavior, update the `README.md` and inline documentation.
6. **Submit a Pull Request:** Open a PR against the main branch. Provide a clear and detailed description of the changes.

## Code Standards
- Code must be formatted consistently (we recommend `black` or standard Python formatting guidelines).
- Provide type hints for function arguments and return types where applicable.
- Add tests for new functionalities in the `tests/` directory.

We appreciate all contributions, from bug fixes to new features. Welcome to the Antigravity Agent Ecosystem!
