# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest master | :white_check_mark: |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities directly to our security team via email. **Do not create public issues for security vulnerabilities.**

Email: **security@thenovanodes.com**

## Response Timeline

- **Acknowledgement:** We aim to acknowledge receipt of your vulnerability report within **48 hours**.
- **Resolution:** We target providing a security patch or mitigation within **7 days** for critical and high severity issues.
